The Mnemosyne approach

Experience becomes
continuity.

An agent should carry useful experience forward, understand what supports it, and adapt when that evidence changes. Mnemosyne connects those moments into one inspectable memory lifecycle.

Evidence that changes

Keep the next
decision current.

A corrected fact should change the guidance that depends on it.

Corrections carry through

Preserve the original history while superseding a changed source. Dependent lessons, summaries and handoffs become inactive, so obsolete guidance stops moving forward.

Freshness before reuse

Explicit source checks distinguish confirmed, changed and unavailable evidence. Action read sets revalidate declared local dependencies immediately before your application considers the action.

Experience that earns reuse

Learn from the work.
Keep the evidence.

Turn selected experience into reusable guidance with a visible path from proposal to trial to outcome.

Propose, then test

Bound observation and reflection work with explicit callbacks and budgets. Proposed skills stay outside ordinary advice until the controller records a passed trial.

Confidence can change

Attribute success and failure to the memories actually used. Recheck supporting evidence before reuse, and retire dependent guidance when its sources change or fail.

Continuity through change

Move forward.
Keep your history.

Start beside the memory system your agents already use, and increase adoption as evidence accumulates.

Begin with coexistence

Connect a read-only adapter to existing search. Copy the source records your agents retrieve, then use paired recall checks to move from shadow to assist to local preference. The old store stays connected and unchanged.

Keep control of the transition

Return routing to the existing system when needed. Choose a reviewed full export import, inspect source bytes, undo unchanged batches and rehearse whole-database recovery. Progress reports cover the queries observed so far.

Measure the effect on your agents

Evaluate the
whole outcome.

Useful memory should help an agent complete the right work without carrying stale advice into the next action.

Matched conditions

The evaluation harness compares no memory, recent history, lexical memory and adaptive context with one chosen reader, isolated stores and declared budgets.

Benefit and failure stay visible

Measure answer and action correctness, grounding, stale actions and positive or negative transfer. The included scripted examples verify the evaluation mechanics; use your own reader and tasks to measure model performance.

A memory lifecycle you can own.

Mnemosyne gives your application source recovery, correction propagation, explicit learning controls and gradual adoption. You choose which sources to capture, what to share, which providers to use and which actions your agents may take.

Inspect the complete capability guide and operating boundaries to choose a configuration for your application. Source citations and controller trials make evidence visible; your own evaluation establishes whether that evidence improves the work.
