    What this run verifies, and its limits

    The recorded run includes source persistence, shared handoff, private-record isolation, correction cascades, context budgeting and live-store deletion. Load the inspector or read every check in the raw JSON.

    Reproduce it with npm run demo npm run demo:learning. All records are synthetic. This page reads a saved run; it does not connect to your memory database.

    A longer history is useful.
    A reliable one is better.

    Mnemosyne keeps the relationships around a memory: where it came from, who can see it and what changes when its source does.

    Corrections travel with the facts.

    Supersede a source and its derived lessons become inactive. Keep the history for inspection, while current context moves on.

    Hand over the unfinished work.

    Checkpoints preserve decisions, constraints, rejected approaches and the next action. Share them deliberately with the next agent in your workspace.

    Let reflection earn its place.

    An optional model pass can propose a new lesson. Your controller validates it before commit. Budgets, source checks and duplicate rejection keep the process bounded.

    See what the agent receives.

    Compile a budgeted context packet with citations, conflicts and uncertainty. Inspect the records, export your owned data or purge it from the live store.
