    A few useful details

    Before you
    connect it.

    See every capability ↗
    How is this different from a vector database?

    Mnemosyne connects retrieval to the rest of an agent’s memory lifecycle: original evidence, task state, two time axes, correction history, source checks and tested skills. Mnemosyne Recall uses scoped relevance scoring by default. Optional semantic search and reranking extend it while keeping the same ownership and evidence checks.

    Can I keep my current memory system?

    Yes. Connect a read-only legacy adapter to the gradual bridge, then start in shadow mode. It copies eligible retrieved memories and compares recall before increasing local reliance. It continues checking the original store, including in prefer mode. Full migration is also available through supported export profiles.

    Which agents and models can I connect?

    Use TypeScript, the Python HTTP client, CLI, MCP or authenticated HTTP. Provider adapters expose scoped memory operations and virtual files through supported tool-calling interfaces. Your host supplies the model, account and integration; these interfaces do not import consumer account memories automatically.

    Can memory intelligence run on my device?

    Yes. Mnemosyne On-Device Intelligence provides optional CPU embeddings and reranking. Provision the supported runtime and model weights explicitly, then use the cached models offline. The default local store and lexical recall work without models or an API key; observation and reflection still need a provider you configure. Explore on-device setup.

    What does it cost to run?

    Mnemosyne is MIT licensed, with no software license fee. The local store and default lexical retrieval need no API key or model call. Optional embedding, observation and reflection providers have their own costs, as does your infrastructure. See the local and provider paths.

    Where does my data live?

    The Mnemosyne Local Engine stores data in a database file you control. Optional embedding, extraction or reflection providers receive only the inputs your application supplies. The database and backups are not encrypted by Mnemosyne; protect their filesystem access and choose providers deliberately.

    What is ready to try today?

    The v2.0.0-rc.9 npm candidate includes both engines, the recall upgrade, temporal context, optional CPU inference, persisted skill gates and gradual migration. Install the exact version or choose the next channel. The published recall measurements remain the frozen rc.8 study; this packaging release does not represent a new benchmark run. The Python client remains available from source. The demos are saved integration runs; the corpus results measure evidence coverage. Generated-answer quality, hosted synchronization and enterprise identity remain outside the verified release. Read the release boundaries.
