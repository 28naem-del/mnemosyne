# Mnemosyne visual identity

The identity connects two arches into one continuous memory mark. Use the same silhouette across the repository, website, social cards and product surfaces. The visual language is dark, precise and spacious: the evidence must remain as legible as the opening scene is memorable.

## Assets

- [Logo](assets/mnemosyne-logo.svg): editable, self-contained vector with a navy field and mint mark. Keep its proportions and clear space intact.
- [Repository and social banner](assets/social-preview.svg): editable 1280 × 640 master.
- [Social preview](assets/social-preview.png): raster export for GitHub sharing; keep below 1 MB. The SVG and PNG must show the same design.
- [Website favicon](site/favicon.svg): compact twin-arch variant. The website's inline mark shares the same geometry.

Do not add product claims, release numbers or badges to the logo itself. Asset SVGs contain no scripts, embedded fonts, remote images or external resources. Preserve accessible names and descriptions.

## Color and type

- Navy `#070b12`: primary field.
- Pearl `#edf2f9`: primary text.
- Mint `#b8f6dd`: logo, focus and primary actions.
- Blue `#9abfff`: supporting links and selected evidence.
- Slate `#9aa9be`: secondary text.
- Panel `#111b2a` and rule `#263141`: restrained separation.

The website's active tokens are defined in [cinematic.css](site/cinematic.css). Helvetica Neue / Helvetica / Arial carry display and body copy. Native monospace is reserved for code, coordinates and evidence identifiers. Keep paragraphs readable on phones; important information must not live only inside a graphic.

## Interaction and accessibility

The website opens with a native contour that is visible immediately. Interactive 3D replaces it only after the first successful render. The contour remains a complete fallback when graphics support is unavailable. Respect reduced motion, keep a motion toggle and preserve keyboard operation, visible focus and touch scrolling. A compact mobile menu must keep navigation available.

The evidence and learning demonstrations present recorded, synthetic runs. Do not imply that their browser presentation is a live model. Explain controls and state changes in text, including correction, retirement and source inspection. Documentation uses one reading column with a local navigation index.

## Product language

Lead with observable behavior: an agent can recover a source, reuse a tested procedure, discover changed evidence and carry work into another session. Link measured claims to their protocol and limits. Retrieval coverage is distinct from generated-answer quality. The source release remains a release candidate; package-registry availability has its own publication step.

Use Mnemosyne names for our interfaces and workflows. Preserve actual dependency identifiers, interoperability names and required credits in technical documentation and notices. Brand ownership must never imply ownership of a third party's code or research.
